# This list is deliberately minimal because the service is memory-bound, not
# CPU-bound. The two fp32 ONNX sessions already account for ~200 MB of resident
# memory, so on a 512 MB instance an unnecessary import is the difference
# between running and being OOM-killed. Measured import cost of the packages
# that used to be here but are not needed to serve:
#
#     scikit-learn   ~46 MB   (not imported anywhere in the codebase)
#     pandas         ~44 MB   (offline benchmark only)
#     PyMuPDF        ~23 MB   (PDF ingestion only)
#     pdfplumber      ~4 MB   (PDF ingestion only)
#
# Ingestion, evaluation and tests run offline on a developer machine, so their
# dependencies live in requirements-offline.txt. Install that locally:
#
#     pip install -r requirements-offline.txt
#
# ---------------------------------------------------------------------------
